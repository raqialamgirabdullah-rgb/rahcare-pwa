# Hadith data (Research page, "হাদিস" mode)

`hadith-chunks/` is generated by `tools/build-hadith.js` from the editions in
[fawazahmed0/hadith-api](https://github.com/fawazahmed0/hadith-api) (the project itself is released under The Unlicense, public domain):
`ara-*` (Arabic) and `ben-*` (Bengali) for Bukhari, Muslim, Abu Dawud, Tirmidhi, Nasai, Ibn Majah, Malik, Nawawi (40) and Arabic only for Hadith Qudsi (40).
The Arabic text and the Bengali translations belong to their original authors/publishers; the Unlicense covers the API project's own code and
packaging, not necessarily every text inside it. Check the upstream `References.md` before using this data outside this research tool.

- Hadith grades (Albani, Zubair Ali Zai, ...) come from the same source (Abu Dawud, Tirmidhi, Nasai, Ibn Majah, Malik only) and are translated word by word into Bengali labels.
- Search index: `hadith-chunks/i/` (256 shards, word → hadith ids). Word normalization is in `hadith-norm.js`; it must stay identical for building and searching, so rebuild the data after changing it.
- Rebuild: sparse-clone the upstream repo's `editions/`, then `node tools/build-hadith.js <editions-dir>`.
